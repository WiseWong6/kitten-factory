# 小猫加工厂 · 游戏体验版

直接打开本目录的 `index.html`，不需要服务器。原动效入口仍是上一级 `index.html`。

## 怎么玩

1. 点色盘加入豆子，一杯 12 颗，最多三种颜色。可以撤回或清空，也可以点“试试三花”快速填入一杯。
2. 豆子落稳后点击“开始做猫”，观看磨豆、接粉、滴液、喷色与猫咪出厂。声音默认关闭，点击播放条的“声音关”开启。
3. 做完自动打开猫卡。点“保存猫卡”下载图片；在小红书环境中改为保存到相册。
4. 右上角猫饼按钮打开收藏夹，一行五个，每页十五个；点猫饼查看对应猫卡。
5. “再做一只”开始下一杯。重播与拖进度只回看当前批次，不能重复获得同一批猫。

最容易尝试的配方：白 6 + 橘 3 + 黑 3 是三花；黑 12 是黑猫；白 12 是纯白；暖灰 7 + 白 5 是小葵。其他配方可自行探索。

## 已实现

- 手动加豆、长按连续加豆、豆仓实时显示投入颜色；没有自动补下一批豆子。
- 十五种已知配方；小葵爆表怒叫、纯白机器故障演出沿用原版。
- 未命中生成自创猫，使用玩家投入的主色、辅色、点缀色；随机脸块、纯色/大块/条纹/斑点、袜子、尾环、眼睛颜色，保持现有轮廓和走路姿态。
- 每批只生成一次外观。动画、猫饼、猫卡使用同一份记录，刷新恢复后仍是原来的猫。
- 已知猫重复获得累计次数；自创猫分别收藏。制作完成时记录，收藏页打开时暂停制作，关闭恢复原状态。
- 独立 900 × 1200 PNG 猫卡，不包含界面按钮。普通浏览器使用图片下载，小红书检测到接口后使用临时文件与相册接口。
- 本地收藏：普通浏览器本地存储；小红书新客户端专用缓存、旧客户端兼容降级。分批保存、读取核对、旧数据迁移；存储失败时保留当前会话结果并提示保存猫卡。
- 暂停、重播、进度、倍速、音效、时间；页面隐藏停止推进，键盘空格与 R 可操作。游戏需玩家点击启动，没有自动循环生产。

## 文件与原版关系

游戏专属代码和样式都在本目录。机器绘制、十五种角色和声音继续引用上一级源文件，保持原版造型。共享代码只增加三个默认不启用的扩展：自创毛色绘制、玩家豆色列表、手动配豆时禁用自动补豆音效；原动效无这些字段，保持原行为。

本次目标是本地可玩体验，**没有制作游戏 ZIP，也没有上传平台**。上一轮动效 ZIP 是历史适配产物，不是游戏交付包。后续确认玩法后再为游戏单独做旧 WebView 兼容、收拢资源、移除普通浏览器下载分支、校验和打包。

## 验证

执行 `node 游戏/verify.cjs`：十组游戏检查通过，覆盖十五种配方唯一性、输入边界、随机结果稳定、重复收藏、整轮制作和重播、模态暂停/返回、后台时间、刷新恢复、存储失败、原生接口版本判断/迁移/拒绝权限。模拟绘制覆盖十五张已知猫卡与 120 个自创猫卡。

另运行 `node verify.cjs`（33 项）、`node verify-sound.cjs`（7 项）、`node verify-meow.cjs`（14 种普通猫的口型/声音检查），全部通过。只做代码、模拟事件和画布调用检查，没有代操作浏览器、截图或听音；实际画面、图片下载、真机相册和听感由用户体验确认。

收藏保存在当前设备，不保证永久保留或跨设备同步。相册图片可留下视觉结果，但不是可导入的游戏存档。
