# 小猫加工厂 · 游戏体验版

直接打开本目录的 `index.html`，不需要服务器。原动效入口仍是上一级 `index.html`。

## 怎么玩

1. 点选一至三种颜色。单色为 100%，两色默认各半，三色默认三等份；重复点同色不会加豆。拖动配色条分界调整比例，颜色旁的 × 可删除；支持撤销与清空。
2. 选一种颜色就能点击“开始做猫”；先自动落豆，再磨豆、接粉、滴液、喷色与猫咪出厂。声音默认关闭，点击播放条的“声音关”开启。
3. 做完自动打开猫卡。点“保存猫卡”下载图片；在小红书环境中改为保存到相册。
4. 右上角猫饼按钮打开「猫咪收藏夹」，一行五个，每页十五个；点猫饼查看对应猫卡。
5. “再做一只”开始下一杯。重播与拖进度只回看当前批次，不能重复获得同一批猫。

点底部「快来抄作业」打开配方本，查看全部十五只猫的颜色比例，点「使用配方」自动填入，再点开始即可。已收藏的猫显示「已拥有」，无法再次通过配方本填入；刷新后同样生效。纯橘直接出大橘，纯黑出黑猫，纯白出白猫；白 50%、橘 25%、黑 25% 是三花。配色条也可聚焦后用左右方向键微调，按住 Shift 每次调 5%。

匹配时颜色组合需相同，总比例偏差（各色差值绝对值之和的一半）不超过 12 个百分点，选最近的已知配方；不命中生成自创猫。两种银渐层的区间分开。大橘也兼容旧橘 75%、奶油 25% 配方。旧收藏保留原匹配版本，避免新规则改变已有随机猫。

主游戏画面固定 3:4，画面和操作区一起等比缩放，外侧为深蓝留边；播放条在画面外。收藏、配方本和猫卡弹窗限制在画面内部，内容过多时内部滚动。猫卡仍为 900 × 1200。

左上角标题下方显示「Created by @歪斯Wise」。选色区预留固定的比例调整空间，未选色、选色和清空时，底部制作按钮与「快来抄作业」保持在同一位置。

## 已实现

- 选色与比例调整、十五只猫的配方本、一键填入；豆仓实时预览，启动后自动播放落豆。没有自动补下一批豆子。
- 收饼动作：解锁提起、弧线运送、靠近右上角后倾倒、猫饼缩小入库、图标轻弹、手柄回位。入库声音与动作同步；暂停和回拖由同一时间控制。
- 十五种已知配方；小葵爆表怒叫、纯白机器故障演出沿用原版。
- 未命中生成自创猫，使用玩家投入的主色、辅色、点缀色；随机脸块、纯色/大块/条纹/斑点、袜子、尾环、眼睛颜色，保持现有轮廓和走路姿态。
- 每批只生成一次外观。动画、猫饼、猫卡使用同一份记录，刷新恢复后仍是原来的猫。
- 已知猫重复获得累计次数；自创猫分别收藏。猫饼收进入口时记录，收藏页打开时暂停制作，关闭恢复原状态。
- 独立 900 × 1200 PNG 猫卡，不包含界面按钮。普通浏览器使用图片下载，小红书检测到接口后使用临时文件与相册接口。
- 本地收藏：普通浏览器本地存储；小红书新客户端专用缓存、旧客户端兼容降级。分批保存、读取核对、旧数据迁移；存储失败时保留当前会话结果并提示保存猫卡。
- 暂停、重播、进度、倍速、音效、时间；页面隐藏停止推进，键盘空格与 R 可操作。游戏需玩家点击启动，没有自动循环生产。

## 文件与原版关系

游戏专属代码和样式都在本目录。机器绘制、十五种角色和声音继续引用上一级源文件，保持原版造型。共享代码只增加三个默认不启用的扩展：自创毛色绘制、玩家豆色列表、手动配豆时禁用自动补豆音效；原动效无这些字段，保持原行为。

已生成游戏小工具 ZIP：`../交付文件/小猫加工厂-游戏小工具.zip`，同内容预览入口为 `../交付文件/小工具游戏预览/index.html`。游戏包经过旧版手机兼容处理，资源全部在包内，保存猫卡仅使用小红书相册接口；普通浏览器中的原版仍可下载图片。上一轮动效 ZIP 为独立历史产物。尚未上传平台，也未进行小红书真机验收。

从项目根目录执行 `python3 游戏/小工具适配/build.py` 复现打包。执行 `node --expose-internals 游戏/小工具适配/verify.cjs` 和 `CAT_GAME_BUILD="$PWD/交付文件/小工具游戏预览" node 游戏/verify.cjs` 检查实际产物。完整摘要见 `../交付文件/游戏小工具-校验摘要.md`。
