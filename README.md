# 小猫加工厂

小猫加工循环动效与选色做猫收藏游戏。

## 打开

- [动效](index.html)：完整的咖啡加工循环，双击直开、离线运行。
- [游戏](游戏/index.html)：选色配方做猫、配方本与猫咪收藏。

底部为统一播放条：播放／暂停、进度拖动、重播、倍速、声音开关与时间。声音默认关闭。

## 结构

| 目录 | 用途 |
| --- | --- |
| `assets/`、`vendor/` | 运行必需的素材、音效与绘图库；声音素材署名见 `assets/audio/素材来源.md` |
| `游戏/` | 游戏页面与检查 |
| `检查脚本/` | 动效、造型、口型与音效检查 |
| `小工具适配/` | 动效打包脚本与公共兼容代码 |
| `tools`（导出） | 确定性 4K 导出工具见 `渲染工具/export-4k.cjs` |

根目录 `cat.js`、`timeline.js`、`scene.js`、`sound.js` 为动效与游戏共用代码；`cat-review.html`、`小葵.html`、`音效试听.html` 是检查入口。

```sh
node 游戏/verify.cjs
node 检查脚本/verify.cjs
node 检查脚本/verify-sound.cjs
```

参考照片、美术审核稿与评审截图仅保存在本地，不入公开仓库。遵守上级目录的统一播放控件与项目约定。
